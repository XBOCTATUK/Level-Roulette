# Levels Roulette

This mod <b>adds</b> a <b>REAL wheel of fortune</b> to <i>GD</i>.<br>
<i>Want to know what level you'll get?</i>

## Features
- A <b>button</b> in the level search screen that opens the popup with <b>Start</b> button
- <b>A real wheel of fortune</b> that selects a <i>random level</i> from the list.
- A <b>native tool</b> (can be enabled in the mod settings) for creating lists of levels that you can <b>switch between</b>.
